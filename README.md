One picture summing up Thursday 19 November 2026: **33 stories in one
image, MAP-LED** — the world map is the hero.

- A full world map (Natural Earth coastline) dominates the top half,
  with all 33 stories pinned on it by number.
- Six stories are called out directly on the map, each with its own
  picture and a leader line to its pin: the Trump–Xi–Putin summit
  (Shenzhen), the Crimean Bridge strike, Iran's Gulf strikes, the
  ICJ Rohingya ruling (The Hague), Van Gogh's $190.4M record
  (New York), and Cyclone Xavier (Rarotonga).
- Below the map, a numbered index lists all 33 stories with their
  headline and city, followed by a DATA CHECK strip (33/33 verified).

`main.py` (Python 3.13, standard library only) copies `entry.png`
into `MAKEFUN_OUTPUT_DIR`. The image is pre-rendered and fixed, so
both runs write identical bytes.
